# סטודיו פרספקס

מחולל בדפדפן למעמדי הוקרה מפרספקס בחיתוך לייזר: תלת־ממד, עורך 2D בסגנון קנבה, הדפסת UV מאחור (הפוכה במראה), מעמדים, תצוגה מדהימה ומחירון.

- `index.html` הוא האתר המלא, קובץ אחד. אין צורך בבנייה ב־Vercel.
- קוד המקור ב־`src/`. אחרי שינוי מריצים `./build.sh` כדי לבנות מחדש את `index.html`.
